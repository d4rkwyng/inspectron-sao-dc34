## Fiction frame (unchanged)

The INSPECTRON BROADCAST AUTHORITY, Licensing Division, Pirate Station
Amnesty Program. Each case file, correctly concluded, yields one channel of
record (NNN.N). The receiver is the examiner: dial it on the INSPECTRON 34
and the programming it licenses unlocks. CRT phosphor aesthetic kept as-is
(green glow, scanlines, snow, warmup animation, seal, stamps).

**The meta-arc (new):** cases CF-00→CF-08 escalate; CF-09 reveals the
Authority never existed. File not found. Dial the error.

## Universal tuning convention (footer, every page)

> The dial takes four significant figures, point before the final digit.
> Shorter numbers pad with leading zeros: channel 42 reads 042.0; the year
> 2026 reads 202.6.

This one rule maps every answer: 1993→199.3, 80→080.0, 4004→400.4,
1704→170.4, 11→011.0, 23→023.0, 66→066.0, 404→404.0.

## Receiver operation sheet (index page — UPDATED to match firmware)

```
1. Hold CH+ and CH- together ....... CHANNEL GUIDE appears
2. Press MODE ...................... FREQUENCY TUNER (the dial)
3. CH+/CH- spin the digit, MODE hops to the next digit
4. Hold MODE ....................... channel commits
```
(Verified against code.py: combo → guide.run_guide → "dial" →
tuner.run_tuner; tuner hints show CH+/-=DIGIT MODE=NEXT HOLD=TUNE.)

## The ten case files

### CF-00 — SIGN-ON: STATION IDENT · Class I · START HERE
- **Answer: 034.1** → `/secret/ident.gif` (SMPTE bars ident)
- **Role:** onramp. Teaches guide/tuner mechanics; near-free answer.
- **Page:** Authority "proof of reception" notice: every licensed operator
  must first tune the Authority's own ident. "Our channel of record is the
  convention you are standing in, subchannel one." (DEF CON 34 → 34.1.)
  Also carries the full receiver-operation sheet inline.
- **Exhibit:** NEW `gen_smpte.py` → `ident-card.png`: SMPTE color bars
  with "IBA · LAS VEGAS · SUBCHANNEL 1" slug. No digits "34" on the card.
- **On-device payoff:** dead channel 34 comes alive as CH 34.1.

### CF-01 — FIRST TRANSMISSION · Class I
- **Answer: 199.3** → `/secret/defcon1.gif` (DEF CON 1, 1993)
- **Port of old CASE 001 (sign-on), page kept nearly verbatim.**
- **Page:** station history plaque: "FIRST BROADCAST: SANDS HOTEL & CASINO,
  LAS VEGAS. ROUGHLY ONE HUNDRED VIEWERS. ONE MAN RAN THE BOARD. …
  DIAL OUR SIGN-ON YEAR." → DEF CON 1 was 1993.
- **Exhibit:** existing `testpattern-001.png` (retitle text via
  `gen_testpattern.py` if needed).

### CF-02 — KNOW YOUR SET · Class II · APPARATUS REQUIRED (bumped from I — playtested as the hardest non-audio case)
- **Answer: 080.0** → `/secret/gadget.gif` (0x50 = 80 decimal)
- **Port of old CASE 002 (Form 345), copy retuned to the new answer.**
- **Page:** Form IBA-345, Notice of Type Acceptance: "Every receiver
  carries its type-acceptance plate at the standard address. The plate is
  read, never written. The maker's mark is LIFE; the set answers to its
  name. State the address for the record — the Authority speaks decimal."
  Chassis markings SDA/SCL/GND. Solver probes I2C (scan finds 0x50, or
  reads INTERFACING.md) → 0x50 hex = 80 → 080.0.
- **Exhibit:** `form-345.png` regenerated via `gen_form345.py` with the
  updated wording (old plate riddle pointed at the retired 080.5 answer).

### CF-03 — COUNT THE FRAMES · Class II · FILM EXHIBIT
- **Answer: 400.4** → `/secret/silicon.gif` (Intel 4004)
- **NEW page.** The Authority's "first master control processor."
- **Page:** engineering-film dossier: "November 1971. Four bits wide,
  twenty-three hundred transistors, and it ran the whole station. Dial the
  model." Verification line for the careful: "the model number reads the
  same in both directions, and its digits sum to eight." (4004 ✓✓)
- **Exhibit:** NEW `gen_filmreel.py` → `mcp-reel.gif`: short film-leader
  countdown + stylized die-shot pan with a stuttering FRAME counter; the
  counter's skipped frames land on 4·0·0·4 one digit at a time for solvers
  who step frame-by-frame (secondary confirmation channel, honors the
  title). Counter never shows a contiguous "4004".
- **Leak note:** the literal strings 4004/400.4 stay forbidden; the clue
  text gives 1971 / four bits / 2300, never the model.

### CF-04 — THE ONLY WINNING MOVE · Class III · AUDIO EXHIBIT
- **Answer: 170.4** → `/secret/wopr.gif` (WarGames, code CPE1704TKS)
- **Port of old CASE 010 (sign-off) — asset reused UNCHANGED.**
  `signoff.wav` already carries Bell-103 AFSK: "GREETINGS PROFESSOR
  FALKEN … LAUNCH CODE FOLLOWS: CPE1704TKS / STRIP THE LETTERS. KEEP THE
  DIGITS. DIAL." plus a reversed-copy red herring. `gen_signoff.py` /

- **Page:** program log, late movie "SHALL WE PLAY A GAME?" (1983),

  (minimodem --rx 300, or by ear + spectrogram) → 1704 → 170.4.
- **Class note:** HANDOFF said "med"; a modem decode is honestly Class III.
  TODO: keep III, or add a softer in-page hint to call it II.

### CF-05 — SIGNAL INTRUSION · Class II
- **Answer: 011.0** → `/secret/maxheadroom.gif` (WTTW Chicago = ch 11)
- **NEW page.** The 1987 Max Headroom broadcast intrusion, Authority-ized.
- **Page:** incident report, 22 NOV 1987, 2300 hours, "the second city":
  a masked pirate seized the tower of a public station mid-Doctor Who.
  Never caught. "The Authority does not forgive the interruption. It
  forgives the station. Dial the seat that was stolen." → WTTW = ch 11.
- **Exhibit:** NEW `gen_intrusion.py` → `intrusion-still.png`: heavily

  original pastiche, no likeness of the actual footage.
- **On-device payoff:** dead channel 11 comes alive.

### CF-06 — TEST CARD LINEAGE · Class III · STATION KNOCK
- **Answer: knock CH 3 → CH 6 → CH 23; final/fallback dial 023.0**
  → `/secret/testcardf.gif`
- **NEW page.** BBC test-card dynasty: Card C (1948, monochrome), Card F
  (1967, the girl, the clown, the blackboard), Card W (widescreen). Each
  card is known by a single letter; the alphabet numbers them: C=3, F=6,
  W=23.
- **Page:** "Succession record" of the Cards, presented as three lineage
  entries with era clues and their letters. Instruction: "Honor the
  succession ON YOUR SET: visit each seat in order of accession. The last
  seat is empty — it always was." (CH 3 and CH 6 are live meme channels;
  CH 23 is dead static → after unlock it comes alive.)
- **Exhibit:** NEW `gen_testcards.py` → `lineage.png`: triptych of three
  original test-card pastiches (mono circle card / color grid card with
  center vignette / widescreen card), letters C, F, W printed on-card.
- **Firmware coupling:** the knock = ordered SURF visits 3, 6,
  23 during playback. Until it ships, dialing 023.0 unlocks (current
  behavior) — page wording covers both ("visit" reads as surf; the dial
  convention rescues anyone who tunes 023.0 directly).
- **Leak note:** letters C/F/W appear; digits 3/6/23 do NOT appear as a
  sequence anywhere. "023.0"/"0230" forbidden.

### CF-07 — TRANQUILITY DESCENT · Class III · STATION KNOCK
- **Answer: knock (dial) 063.0 → 064.0 → 066.0; final/fallback 066.0**
  → `/secret/apollo.gif`
- **NEW page**, reusing the existing `dsky.png` DSKY exhibit (regenerate
  via `gen_dsky.py` with descent-flavored readout if desired).
- **Page:** relay-station dossier, Sea of Tranquility, 20 JUL 1969. The
  guidance computer flew the descent as numbered PROGRAMS: braking,
  approach, and the one under which the Eagle actually set down — P63,
  P64, P66 (P65 was never flown; the commander went semi-manual instead).
  Instruction: "FLY THE DESCENT ON YOUR DIAL. Three programs, in order.
  The set holds its breath between them; the landing is the license."
  1202-alarm flavor text — five alarms total (1202s + one 1201).
- **Firmware coupling:** channels 63/64 do not exist in the surf lineup,
  so this knock is DIALED on the tuner: two intentional misses (NO SIGNAL
  static = "holding breath") then 066.0. The knock detector should
  therefore watch dialed frequencies, not just surf position. Today,
  dialing 066.0 alone unlocks — the page's "landing is the license" line
  keeps that honest.
- **On-device payoff:** dead channel 66 comes alive.
- **Leak note:** P63/P64/P66 must appear (that IS the history); forbidden
  strings remain "066.0"/"0660" — the aha is the dial convention + which
  program landed. Anniversary bonus: today is Jul 20.

### CF-08 — FIELD CONTACT · Class ★ (SOCIAL) · NO CHANNEL OF RECORD

## Leak checker (`check_no_answers.py`) — new forbidden set

With-dot and no-dot forms of: 034.1, 199.3, 080.0, 400.4, 170.4, 011.0,
023.0, 066.0, 404.0 — EXCEPT the two staged appearances: "404" (bare, on
CF-09/404.html only; "404.0"/"4040" still forbidden) and nothing else.
Byte-scan all files including new binaries; generators retry-with-seed
until assets are clean (same trick as the noise tile). Keep external-URL
and asset-reference checks. Add a check: no case page contains the literal
knock sequences ("3-6-23" etc.).

Note: bare "0800"/"0110"-style no-dot forms are prone to false positives
inside binary assets; scan binaries only for the dotted forms + the no-dot
forms as standalone ASCII runs (regex with non-digit boundaries) rather
than raw substring, so a PNG byte stream can't trip it accidentally.
HTML/text files keep the strict substring scan.

## Playtest amendments (first playtest pass, 2026-07-20)

Playtest: 10 solvers, non-technical (retired teacher) → expert
(puzzle-hunt designer), each attempting all cases from a spoiler-free
player brief. 10/10 would recommend. Solve rates: every case 9–10/10
except CF-04 (realistically ~6/10; the bottom four are hard-walled by the
modem decode).

Accepted changes:

1. **Tuning convention — fix the padding ambiguity (REAL BUG).** "Pad with
   leading zeros" literally maps 404 → 040.4 (one tester dialed exactly
   that and failed; the expert flagged the same contradiction). Rewrite:
   "Whole numbers are channels: channel 11 reads 011.0; error 404 reads
   404.0. Four-figure numbers (years, codes) take the point before the
   final digit: 1993 reads 199.3." Also print the convention IN BIG TYPE
   on the CF-00 page (5 testers asked), not only the footer.
2. **CF-04 — add a baud-rate thread.** The 4 low-tech testers had zero
   thread to pull ("laptop-owners only"). Add an in-fiction hint in the
   program log: timestamp the modem segment `03:00 — [DATA]` (a hidden
   300) and/or a "the Bell rings at three hundred" flavor line. Keep the
   canonical CPE1704TKS payload: the guessability of "WarGames launch
   code" via Google IS the intended no-laptop side door (a non-canonical
   code was considered; rejected — accessibility wins). Add a volume
   warning ("MONITOR AT LOW GAIN") for hearing-aid users.
3. **Knock cases — accept BOTH entry methods in firmware.**
   Testers split evenly on whether "visit each seat" means surfing
   CH+/CH− or dialing the tuner; several abandoned a correct idea when
   the set gave no reaction. The knock detector must accept surf-visits
   AND dialed sequences for both CF-06 and CF-07, and give per-step
   feedback (antenna LED blip / brief "CARRIER HELD" OSD) when a step
   registers. Also teach the mechanic ahead of time: add one cryptic line
   to the receiver-operation sheet ("The set also honors CONDUCT: some
   licenses are granted for how you surf, not what you dial.").
4. **CF-06 — clue the alphabet-index leap.** The printed years (1948/
   1967) are a stronger-looking wrong path than the answer; 4 testers
   needed outside help. Add one whispered line: "count each card's place
   in the procession." Keep the years.
5. **CF-02 — keep the social gatekeep, add a side door.** Bottom-third
   testers solved it only by asking strangers — which the panel itself
   called perfect for DEF CON. Add a smallprint nudge: "any badge that
   speaks, any village that listens" + note the spec sheet is public
   (INTERFACING.md) so software-only players have a path.
6. **CF-09 — add a source-reader layer.** Expert curled the page hoping
   for a real 404. GH Pages: link the index's CASE FILE 09 entry to a
   path that does NOT exist so the hosted site serves site/404.html with
   a genuine 404 status; keep puzzles/master-control.html as the
   file://-safe mirror... simpler: keep the real link to
   master-control.html but hide an HTML-comment easter egg in its source
   for view-source players. (Decide at build; leaning: real link +
   comment egg, since a dead link on file:// is an ugly browser error.)
7. **CF-00 — hide a tiny easter egg on the SMPTE card** for people who
   zoom in (expert: "the exhibit is pure decoration").
8. **Firmware QoL (separate from site):** hold-to-repeat/acceleration on
   tuner digit spin (arthritis feedback); optionally echo "NNN.N" format
   on the tuner screen. Trap table already catches the panel's plausible
   wrong answer 000.0 with a rickroll — keep.

Color: CF-04 is both most-favorite (4 votes — everyone who could
decode called it best-in-set) and most-least-favorite (5 votes) — a
lightning rod by design; the amendments widen its on-ramp without
flattening it. CF-05 (Max Headroom) was the crowd-pleaser: 10/10 solved,
fun 4.6/5. CF-07 hits the hardest emotionally (good tears). Difficulty curve
otherwise matches the Class I→IV ladder.

### Pessimistic re-run (worst-case knowledge assumptions)

Second pass over the same 10, assuming the worst: hard lists of what
each solver does NOT know, low patience, fast quit triggers — and any
solve that leaned on out-of-band knowledge was thrown out.
Realistic solve band per case (optimistic ↔ pessimistic, correct/10):
CF-00 10↔10 · CF-01 10↔10 · CF-02 10↔4 · CF-03 10↔8 · CF-04 6↔4 ·
CF-05 10↔9 · CF-06 10↔5 · CF-07 10↔8 · CF-08 10↔8 · CF-09 9↔8.
Every tier still solves ≥2 cases (CF-00/01 are a solid floor); the median
attendee lands 5–8 of 10.

Later amendments:

9. **Knock per-step feedback is LOAD-BEARING, not QoL** (upgrades
   amendment 3). Under real quit triggers, CF-07 fails low-tier players
   precisely because the dialed knock's two intentional misses look
   identical to failure: low-tier solvers quit at the second NO SIGNAL
   one dial from the unlock, or abandon a correct first step as wrong.
   Firmware must acknowledge a registered knock
   step visibly (antenna blip / "CARRIER HELD"), and CF-07's copy should
   say static-between-programs is EXPECTED ("the set holds its breath —
   twice — between programs"). CF-06 without both-methods acceptance and
   the alphabet clue drops to 5/10 (surf-vs-dial ambiguity alone sank a
   fast googler who dialed everything).
10. **CF-02's floor without stranger-generosity is 4/10 — accepted** (it
    is the apparatus case and the social path IS the design), but two
    testers independently dialed the form number, 345.0. Add 345.0 to
    TRAP_FREQS with a joke/nudge GIF — it's the most common wrong answer
    in the set and currently rewards nothing.
11. **CF-05: add a 009.0 wink.** Three testers' wrong first dial was
    009.0 — which is historically PERFECT (the real intrusion hit WGN
    channel 9 first, then WTTW 11). Trap 009.0 with a "wrong station —
    he moved on" tease. Cheap, delightful, historically accurate.
12. **Spoiler-on-device is real (decide policy).** Both expert testers
    mounted CIRCUITPY first and read every answer out of
    secrets_config.py in minutes; those runs count as
    "privileged access, intended path bypassed." Their device, their
    right — but if unwanted, store FREQS/TRAP_FREQS keys as cheap hashes
    (pure-python FNV of the "NNN.N" string) mapping to gif paths: kills
    casual text-editor spoilers while keeping the table tiny. Requires
    stable slot ordering (sort by hash) + tuner.VERSION bump — decide
    before boards ship. GIF filenames in /secret still hint themes;
    acceptable.
13. **CF-01/CF-05-style trial-and-error is healthy**: several testers
    recovered from one wrong dial and solved (195.3→199.3, 009.0→011.0,
    088.0→011.0). The 3-second NO SIGNAL penalty reads as fair. No
    change.
